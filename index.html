Publicar una aplicación con GitHub Pages

Guía rápida para subir un proyecto a GitHub y publicarlo como una página web mediante GitHub Pages.

01

¿Qué es GitHub Pages?

GitHub Pages es un servicio de GitHub que permite publicar páginas web directamente desde un repositorio.

02

Preparar el proyecto

Antes de publicarlo debemos asegurarnos de que el proyecto contiene un archivo index.html. 

mi-proyecto/
│
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
└── img/
    └── imagen.jpg
Importante: GitHub Pages utilizará index.html como página principal.
03

Crear el repositorio

El proyecto debe estar almacenado en un repositorio de GitHub.

  1. Acceder a GitHub.
  2. Pulsar New repository.
  3. Introducir el nombre del proyecto.
  4. Seleccionar Public.
  5. Pulsar Create repository.
04

Subir el proyecto a GitHub

Desde la terminal podemos inicializar Git y enviar nuestro proyecto al repositorio.

1 git init
2 git add .
3 git commit -m "Primer commit"
4 git remote add origin URL_DEL_REPOSITORIO
5 git branch -M main
6 git push -u origin main
05

Configurar GitHub Pages

Ahora activaremos GitHub Pages para publicar el proyecto.

GitHub → Repository → Settings → Pages
  1. Entrar en el repositAorio.
  2. Abrir Settings.
  3. Seleccionar Pages en el menú lateral.
  4. Buscar Build and deployment.
  5. Seleccionar Deploy from a branch.
  6. Seleccionar la rama main.
  7. Seleccionar la carpeta / (root).
  8. Pulsar Save.
06

Comprobar la publicación

GitHub comenzará automáticamente el proceso de publicación.

Tu sitio está siendo publicado

Cuando finalice el proceso, GitHub mostrará el enlace a la página publicada.

07

Aplicación publicada

Una vez completada la configuración podremos acceder a la aplicación desde cualquier navegador.

URL DE LA APLICACIÓN https://TU-USUARIO.github.io/TU-REPOSITORIO/

Sustituye la dirección anterior por la URL real de tu proyecto.

08

Actualizar la aplicación

Cuando realicemos cambios en el proyecto, podemos actualizar GitHub Pages utilizando Git. 

git add .
git commit -m "Actualizacion de la aplicacion"
git push

Después del push, GitHub actualizará automáticamente la página publicada.
